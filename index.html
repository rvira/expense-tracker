Sync to GitHub

Generate a fine-grained Personal Access Token and paste it below. Your expenses will sync to rvira/expense-tracker in data/expenses.json.
  1. Open github.com/settings/personal-access-tokens/new
  2. Token name: expense-tracker
  3. Expiration: 1 year (or your preference)
  4. Repository access: Only select repositories → expense-tracker
  5. Permissions → Repository permissions → Contents: Read and write
  6. Click Generate token, copy it, paste below
